# 🌳 Árbol de Gratitud | Friends Giving

Sitio interactivo para una reunión de mujeres cristianas, con estilo minimalista y diseño adaptable a celulares.

## Cómo abrir
Abre `index.html` en Chrome o Safari, o desde VS Code selecciona **Open with Live Server**. No requiere instalación.

## Netlify
Conecta el repositorio en Netlify. Sin comando de compilación; directorio de publicación `.`.

## Incluye
- Árbol interactivo con hojas de agradecimientos
- Mensajes anónimos
- Modal para leer cada hoja
- Modo proyección
- Persistencia local por navegador

**Aviso importante:** Esta versión HTML sirve para pruebas y visualización. Los mensajes se guardan **solo en el navegador local**; no se comparten entre diferentes celulares. Para una reunión simultánea se necesita conectar un servicio de datos en tiempo real como Supabase.

La versión React preparada originalmente es un proyecto separado. Esta primera publicación usa HTML autónomo para que pueda ejecutarse sin instalación con Live Server.
